# TAVAANA FINANCE

برنامه حسابداری شخصی و مدیریت کسب‌وکار با رابط فارسی و راست‌چین، قابل نصب به‌صورت PWA و دارای ذخیره‌سازی محلی.

## امکانات نسخه 1.3
- چندکاربره محلی: حساب مدیر و کاربران مستقل، هر کاربر با رمز جدا و دفتر مالی جداگانه
- حفظ ورود کاربر تا قفل دستی برنامه؛ پس از خروج/قفل، ورود دوباره لازم است
- مدیریت کاربران توسط مدیر اصلی و امکان فعال/غیرفعال‌سازی حساب‌ها
- تنظیم اندازه نوشته‌ها و انتخاب رنگ رابط از چند رنگ یا رنگ دلخواه
- سازگار با داده‌های نسخه 1.2؛ دفتر مدیر قبلی هنگام مهاجرت حفظ می‌شود
- رمز ورود با هش SHA-256
- ذخیره اطلاعات در IndexedDB
- داشبورد و دفاتر مالی جداگانه: شخصی، ادوانس، تعمیرات و خریدوفروش
- ثبت دریافت و پرداخت
- تعریف کالا، ثبت خرید و فروش و گردش انبار
- ثبت سفارش تعمیر و محاسبه سود خالص
- اشخاص و حساب‌های باز با ثبت تسویه کامل یا جزئی و تاریخچه مانده
- دفتر مستقل تسویه ادوانس: دریافت وجه، خرید واقعی، برگشت وجه و منفعت شخصیِ تأییدشده
- خروجی تراکنش‌ها به CSV سازگار با Excel
- گزارشات، پوسته روشن/تاریک، پشتیبان JSON و بازیابی
- Service Worker برای کش فایل‌های برنامه و اجرای آفلاین پس از اولین بارگذاری

## اجرا
بهترین روش: انتشار روی GitHub Pages یا هر میزبان HTTPS، سپس بازکردن سایت و نصب از منوی مرورگر. برای اجرای محلی نیز می‌توان از یک وب‌سرور ساده استفاده کرد؛ فایل را مستقیم با `file://` باز نکنید چون Service Worker و بعضی قابلیت‌های امنیتی در این حالت فعال نیستند.

## اصلاحات نسخه 1.3
- محاسبه بهای تمام‌شده فروش با میانگین موزون قیمت خریدها، به‌جای اتکا به آخرین قیمت خرید.
- محاسبه میانگین بر اساس تاریخ گردش انبار، برای جلوگیری از اثرگذاری خریدهای بعدی روی فروش‌های قبلی.
- اعتبارسنجی گردش انبار و جلوگیری از مقدار یا قیمت نامعتبر.
- اصلاح تاریخ پیش‌فرض برای استفاده از تاریخ محلی دستگاه، نه تاریخ UTC.
- بهبود زمان آزادسازی فایل‌های خروجی در مرورگرهای موبایل.

## نکات مهم
- اطلاعات مالی در حافظه همان مرورگر/دستگاه می‌ماند. برای انتقال دستگاه از خروجی پشتیبان استفاده کنید.
- رمز ورود در این نسخه قفل محلی برنامه است و جایگزین رمزگذاری کامل فایل‌های پشتیبان یا امنیت سیستم‌عامل نیست.
- ارقام شرکت ادوانس را در دفتر ادوانس ثبت کنید؛ پیش‌پرداخت شرکت به‌خودی‌خود درآمد شخصی محسوب نمی‌شود.
- این نسخه 1.3 است؛ برای استفاده عملیاتی با مبالغ واقعی، ابتدا جریان‌های کاری و گزارش‌ها را با داده آزمایشی بررسی کنید.


## محدودیت امنیتی چندکاربره محلی
این قابلیت برای جداسازی کاربردی کاربران روی یک دستگاه است، نه امنیت سازمانی در برابر دسترسی مستقیم به فایل‌ها/مرورگر یا ابزارهای توسعه. داده‌ها همچنان در IndexedDB همان مرورگر ذخیره می‌شوند و حساب‌ها بین دستگاه‌ها همگام نمی‌شوند. از حساب‌های دستگاه مشترک سیستم‌عامل و پشتیبان‌گیری منظم استفاده کنید.
