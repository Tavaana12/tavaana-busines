# Tavaana Business — نسخه دوم

اپلیکیشن موبایل‌محور و آفلاین برای مدیریت حساب‌های سلمانی و فروش لوازم جانبی موبایل.

## امکانات نسخه دوم
- رابط واکنش‌گرا برای موبایل، با رعایت ناحیه امن صفحه و نوار پایین
- منوی کشویی شامل داشبورد، ثبت‌ها، انبار، گزارش‌ها، تنظیمات و درباره نرم‌افزار
- چهار رنگ ظاهری قابل انتخاب (سبز، آبی، بنفش و نارنجی)
- صفحه «درباره نرم‌افزار» و پروفایل صاحب کسب‌وکار
- امکان ویرایش نام، عنوان، شماره تماس، ایمیل و آدرس از تنظیمات
- مدیریت موجودی، دسته‌بندی کالا و هشدار حداقل موجودی
- ثبت درآمد سلمانی، فروش موبایل، درآمد متفرقه و هزینه‌ها
- گزارش‌های کلی و ماهانه
- ذخیره محلی و پشتیبان‌گیری خودکار داخلی، همراه با خروجی و بازیابی JSON
- زبان فارسی/دری و واحد پول افغانی

## اطلاعات صاحب برنامه
نام اولیه پروفایل: Mohammad Ali Tavaana. شماره تماس و ایمیل در تنظیمات قابل تکمیل هستند؛ عمداً مقدار ساختگی قرار داده نشده است.

## نصب و به‌روزرسانی روی Android
برنامه از طریق GitHub Pages و HTTPS میزبانی می‌شود. پس از آپلود فایل‌های نسخه جدید روی مخزن GitHub، چند دقیقه برای انتشار صبر کنید؛ سپس برنامه نصب‌شده را کاملاً ببندید و دوباره با اینترنت باز کنید تا Service Worker جدید دریافت شود. داده‌های حسابداری در localStorage با همان کلید نسخه اول نگهداری می‌شوند و در به‌روزرسانی عادی نباید حذف شوند؛ با این حال پیش از به‌روزرسانی از تنظیمات خروجی JSON بگیرید.

## نکات مهم
- کاربران متعدد فعلاً روی یک گوشی و یک پایگاه داده محلی مشترک هستند، نه چند گوشی هم‌زمان.
- این نسخه نمونه اولیه است؛ PINها هنوز به شکل امن هش/رمزنگاری نشده‌اند.
- فروش موبایل فعلاً موجودی انبار را به‌صورت خودکار کم نمی‌کند؛ این اتصال باید در مرحله بعد توسعه یابد.
- پشتیبان خودکار داخل حافظه مرورگر است؛ خروجی JSON را در فضای دیگری هم نگهداری کنید.



## نسخه سوم (شاخه توسعه)

نسخه سوم در شاخه `v3-development` در حال توسعه است و هنوز روی نسخه اصلی منتشر نشده است.

### تغییرات افزوده‌شده
- داشبورد واکنش‌گرا و راست‌چین با منوی موبایل/دسکتاپ و رنگ‌بندی قابل انتخاب.
- فروش چندقلمی متصل به موجودی؛ کنترل موجودی کافی و کسر خودکار کالا هنگام ثبت فاکتور.
- محاسبه درآمد فروش، بهای تمام‌شده، تخفیف، سود فروش، مبلغ دریافتی و مانده حساب مشتری.
- دفتر مشتریان، تأمین‌کنندگان، صندوق مرکزی، دریافت‌ها، پرداخت‌ها و ثبت فعالیت‌ها.
- خرید کالا و افزایش موجودی، هشدار کمبود کالا، گزارش مالی و خروجی CSV.
- پشتیبان JSON و بازیابی اطلاعات.
- نگهداری سازگار با کلید داده نسخه دوم `tavaana_business_v1` همراه با ذخیره جدید `tavaana_business_v3`.

### اجرای محلی
نیازمند Node.js 20 برای آزمون‌ها:

```bash
npm test
```

> هشدار: این شاخه هنوز نیازمند بازبینی امنیت ورود، آزمون کامل مهاجرت داده‌های واقعی، و آزمون دستی روی Android و Windows است. آن را تا پیش از تکمیل این بررسی‌ها با شاخه اصلی جایگزین نکنید. اطلاعات هر دستگاه مستقل است و همگام‌سازی بین دستگاه‌ها وجود ندارد.
