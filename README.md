# Tavaana Business — نسخه اول

نرم‌افزار موبایل‌محور و آفلاین برای ثبت حساب‌های سلمانی و فروش لوازم جانبی موبایل.

## امکانات فعلی
- ساخت حساب مدیر و ورود چند کاربر محلی روی همان دستگاه
- ثبت درآمد سلمانی، فروش موبایل، درآمد متفرقه و هزینه‌ها
- ثبت کالا، کد، موجودی و قیمت خرید/فروش
- داشبورد روزانه و گزارش کلی و ماهانه
- ذخیره‌سازی محلی مرورگر و نسخه پشتیبان خودکار داخلی
- خروجی و بازیابی فایل JSON
- رابط فارسی/دری و واحد پول افغانی

## اجرای آزمایشی روی کامپیوتر
بهتر است از یک وب‌سرور محلی استفاده شود؛ در پوشه پروژه اجرا کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر باز کنید: `http://localhost:8000`

## نصب روی Android و استفاده آفلاین
برای نصب به‌صورت PWA، برنامه باید نخست از یک مبدأ امن (HTTPS یا localhost) باز شود تا Service Worker ثبت گردد. پس از بارگذاری و نصب، فایل‌های برنامه در کش ذخیره می‌شوند و اجرای بعدی بدون اینترنت ممکن است. باز کردن مستقیم `index.html` از فایل‌منیجر، نصب PWA و Service Worker را تضمین نمی‌کند.

## نکات مهم نسخه اول
- کاربران متعدد روی یک گوشی و یک پایگاه داده مشترک هستند؛ هم‌زمانی چند دستگاه/شبکه در این نسخه وجود ندارد.
- رمزها در این نمونه اولیه به شکل ساده در ذخیره‌سازی محلی نگهداری می‌شوند؛ برای استفاده واقعی با اطلاعات حساس باید احراز هویت امن‌تر، رمزنگاری پایگاه داده و کنترل دسترسی دقیق اضافه شود.
- نسخه پشتیبان خودکار داخل حافظه مرورگر است؛ برای حفاظت در برابر پاک‌شدن داده‌های مرورگر، باید مرتباً فایل JSON دستی صادر و خارج از گوشی نگهداری شود.
- فروش ثبت‌شده هنوز به صورت خودکار موجودی کالا را کاهش نمی‌دهد؛ این یک مرحله توسعه بعدی است.
- سود فعلی بر اساس درآمد منهای هزینه‌های جاری و بهای تمام‌شده‌ای که هنگام ثبت فروش وارد می‌شود محاسبه می‌گردد.
